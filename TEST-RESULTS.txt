Important test scope
The offline browser interaction fixture temporarily holds AI inputs idle so that
individual keyboard controls can be isolated without enemy fire. The separate
full-match simulation test runs all 17 bots normally through the zone cycle.
Browser tests use low graphics; screenshots document this tested setting.
No uncaught browser exceptions occurred in the passing browser suite.
These tests do not establish photorealism, AAA quality, production security,
universal frame rates, public internet availability, or compatibility with every
physical device. No public server has been deployed. No real phones were tested.
The server is functional infrastructure, not an included ongoing hosting service.

Reproduction
npm install
npm test                      # isolated simulation tests
npm start                     # run in another terminal for network/browser tests
node network-tests.js
For the optional browser test harness only:
npm install --no-save playwright
npx playwright install chromium
# On Linux, system browser dependencies may also be required.
node browser-tests.js

Authoritative simulation tests verify collision, hits, friendly fire, state and
match outcomes. Live browser tests verify room creation, two-human solo play,
movement/weapon/shot replication and disconnects. Protocol tests additionally
verify four-human duos, team capacity and two-human squad public auto-start.
Internet/TLS/LAN router configuration and audio perception need human field testing.
